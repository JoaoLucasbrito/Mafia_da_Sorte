# 🎱 Máfia da Sorte

### Projeto: Jogo de Bingo em Python

## 📌 Sobre o projeto

O **Máfia da Sorte** é um projeto acadêmico desenvolvido em Python, com o objetivo de criar um jogo de Bingo simples e funcional, executado diretamente pelo terminal, sem necessidade de interface gráfica.

O jogo gera automaticamente uma cartela, realiza sorteios aleatórios de números e verifica se o jogador conseguiu completar uma combinação vencedora.

## 🎯 Objetivo

Desenvolver um jogo utilizando os fundamentos da programação Python, colocando em prática conhecimentos adquiridos durante o curso de Análise e Desenvolvimento de Sistemas (ADS).

## ⚙️ Funcionalidades

- Geração automática de cartela 5x5.
- Sorteio aleatório de números de 1 a 75.
- Não permite números repetidos nos sorteios.
- Marcação automática dos números sorteados.
- Espaço central livre na cartela.
- Verificação de linhas, colunas e diagonais.
- Identificação automática do vencedor.
- Exibição da quantidade de números sorteados.

## 🛠️ Tecnologias utilizadas

- **Python 3:** linguagem de programação.
- **Random:** biblioteca para geração de números aleatórios.
- **Visual Studio Code:** ambiente utilizado para desenvolvimento.

## ▶️ Como executar o projeto

1. Instale o Python 3 em seu computador.
2. Clone este repositório ou faça o download dos arquivos.
3. Abra a pasta do projeto no Visual Studio Code.
4. Abra o terminal.
5. Execute o comando:

```bash
python bingo.py
```

6. Pressione ENTER para realizar os sorteios.
7. Continue até completar uma linha, coluna ou diagonal.
